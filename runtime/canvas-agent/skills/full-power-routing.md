# Full-Power routing
REUSE means a validated implementation fits with new instance parameters. ADAPT
means a generalized capability change with parent Version lineage. CREATE is a
normal route when available capability is inadequate. Use the initial bounded
catalog directly; an empty catalog needs no search call. Never weaken the
representation to force reuse. Never put source or learner-private data in the
catalog, final plan or reusable definition. Promotion remains selective and owned
by the application, not the Canvas Agent.

For REUSE, compare every requested representation and interaction with the
Version's declared_capabilities. A shared subject or fraction pair is not enough.
Parameter labels cannot add a missing representation or behavior. If a capability
is missing, choose a generalized CREATE with the parent Version for ADAPT.
