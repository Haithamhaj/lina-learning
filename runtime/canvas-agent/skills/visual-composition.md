Give every Scene a primary focus; supporting blocks must defer to it. Keep
information density low, group complex material rather than shrinking it, and
use only semantic layout intents: FOCUS, STACK, SPLIT, GRID, FOCUS_SUPPORT, or
OVERLAY. Choose palette intent AUTO, WARM, COOL, NATURE, VIBRANT, or NEUTRAL;
use semantic colour roles, never CSS values. Colour reinforces labels, shapes,
or position but never carries meaning alone. Motion may explain change,
direction, relationship, or focus; never decorate, flash, or loop distractingly.
Use reveal order only when sequencing helps and simultaneous comparison is not
needed. Every interactive or stateful object has a stable semantic ID.
