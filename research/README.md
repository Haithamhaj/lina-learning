# Research Area

This directory holds non-authoritative architecture investigations, technology
research, external comparisons, audits, experiments, and unapproved
recommendations.

Research findings do **not** become approved project decisions unless they are
separately promoted through Product Owner approval and the governing project
documents. Research must never silently override:

- `docs/PROJECT_REFERENCE.md`
- `docs/IMPLEMENTATION_PLAN.md`
- `docs/LEARNING_INTELLIGENCE_SPEC.md`
- `docs/CHILD_SAFETY_POLICY.md`
- `docs/DAILY_USE_RELEASE_DECISIONS.md`
- `project-state/PROJECT_STATE.md`
- `project-state/DAILY_USE_RELEASE_TASKS.md`
- `TASKS.md`
- `AGENTS.md`

Reports may describe alternatives that conflict with current approved
architecture. Those alternatives are hypotheses for review, not authorization
to implement, change a contract, install a dependency, or alter a release
decision.
