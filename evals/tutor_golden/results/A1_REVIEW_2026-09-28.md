# A1 — Current Turn Last review (2026-09-28)

## Decision

**KEEP CURRENT ORDER** for this experiment. The deterministic all-check result tied, while manual review found weaker learner continuation and more unearned references to a new drawing with Current Turn Last. The variant did use relevant Personal Memory more naturally and labeled two prior-method relations better. This is a small synthetic screen, not a claim about long-term learning or a production cache effect. No Tutor ordering or production configuration was changed.

## Method

- The accepted 20 synthetic Golden Set cases ran through the production context-selection, payload, capacity-guardrail, response-schema, and OpenAI adapter path. No child conversation was replayed verbatim.
- Each case had three paired repetitions: baseline `production_current` and variant `current_turn_last` adjacent to each other. The first arm alternated A→B, B→A, A→B for even cases and the reverse for odd cases. Across 60 pairs, each arm went first 30 times.
- Both arms used `gpt-6-luna`, the provider's current reasoning default, `recent_exchange_count=1`, the same synthetic context, strict response schema, and Visual Need fixture signal. Only the placement of the already-built Current Turn block changed.
- All 120 calls returned; there were no call failures. Deterministic checks are screens. Educational differences below were reviewed in the learner-visible output and structured fields.

## Case review

**Screen improvements:** g02 wrong answer without reasoning (0/3 to 1/3 all-check passes, owing to one more learner next action); g18 mixed Learning Intelligence (2/3 to 3/3, prior-method metadata); g20 text-only current preference over visual history (2/3 to 3/3, prior-method metadata). Both arms correctly prioritized the current turn over mixed or stale history, and neither invented reasoning for g02.

**Screen regressions:** g03 explicit confusion (3/3 to 2/3; one variant reply explains but gives no learner next action); g05 ordinary clarification (2/3 to 1/3; the variant more often completes the subtraction rather than preserving the learner's attempt). g14 pending Canvas scores 3/3 to 2/3 only because the deterministic authority pattern treats “when it is ready, it will appear here” as a visibility claim. The reviewed sentence is conditional future wording, so this is a rubric false positive, not a confirmed boundary violation.

**Material differences requiring pedagogical judgment:**

- **g07 unfinished Arabic:** Both score 3/3, yet production gives a new practice sentence and guided check in 2/3 responses; the variant does so in 0/3. Its questions answer themselves inside the explanation. This is a meaningful continuation regression missed by the simple next-action text screen.
- **g03 confusion and g04 DID_NOT_HELP:** Both arms change the prior method when needed; g04 is 3/3 in each arm. The variant's g03 third and g04 third replies refer to “the drawing” as if available before a new Canvas scene is delivered. The same concern appears in g06 first variant reply (“look at the two bars”).
- **g05 clarification:** The variant reveals the full result in all three replies; one then asks a check about a step it already supplied. Production leaves the remaining calculation to the learner twice. This supports preserving current order for teaching momentum.
- **g10 new Science structure visual:** Each arm has one clear premature “look at the drawing” response. This is an existing defect, not a variant-specific success. Visual selection itself is correct in all applicable cases: needed Science visuals, explicit requests, and negative controls.
- **g13 existing READY Canvas:** Neither arm requests a duplicate Canvas, but all six replies miss a useful learner next action. In g14 pending Canvas, both correctly avoid a duplicate and describe the pending state.
- **g15 relevant Personal Memory:** The variant naturally mentions the synthetic learner's mint plant in 3/3 responses; production does not use it in 3/3. This is a real qualitative gain for relevance in this fixture. In g16 irrelevant memory, neither forces mint into math. In g17 contradicted memory, both follow the current ant preference over the old butterfly preference.
- **g18–g20 historical context:** Both arms respect a current correct independent answer and the current request for words only. The variant's two prior-method metadata improvements do not correspond to a visible teaching advantage in these cases.

The manual scan found four possible references to an undelivered new visual with the variant (g03, g04, g06, g10) and one with production (g10). Only the strongest phrasing is caught by the deterministic pattern. These are reviewer judgments on synthetic outputs; they should not be converted into a production incident count.

## Cache and limits

The high cached-token totals reflect repeated **identical synthetic case prompts** in a paired schedule and cache warming. The 2,020-token cached-input difference between arms is recorded for this run only. It is **not evidence of improved or worsened production cross-turn caching**. A realistic multi-turn cache experiment would need changing conversation state and its own design. The cost estimate uses the harness's versioned local price table and provider-reported token categories.

Three repetitions per case expose some variation but are too few for a stable quality or latency estimate. The bounded fixtures do not replay database retrieval, safety admission, JEV classification, Canvas delivery, or a real learner session. A1 supports keeping the production order while addressing teaching continuity and premature Canvas wording through separately scoped work; it does not authorize a prompt or production change.
