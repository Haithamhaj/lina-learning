Protected Invariants

Evidence-first: Mastery/confidence are derived views, not source truth.
Current Lina wins: current behavior outranks historical personalization.
Raw source stays: original books and student work are never replaced by AI interpretations.
Grounding ≠ permission: Tutor remains available without a book, source, semantic enrichment, or retrieval match.
Question first: recent context and available sources improve grounding but do not control what Lina may ask now.
Safety is layered: protected baseline cannot be weakened by Parent settings.
Simple runtime: normal Tutor path uses one primary model call; no chain-of-agents by default.
Method evidence: method selection is not effectiveness evidence; only a later observable Lina outcome can be evaluated.
Rebuildable intelligence: derived Events/Evidence/Patterns/Card are versioned and reprocessable.
No premature platform: no microservices, graph infra, generic agent framework, or multi-family SaaS without proof.
