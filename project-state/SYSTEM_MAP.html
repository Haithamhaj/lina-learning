Conversation Context v2

SessionTemporary conversational container. New Sessions begin conversationally fresh; prior raw transcripts are not injected by default.
Multimodal TurnLogical Turn may bundle text, transcript, and original asset references. Derived Vision/OCR remains rebuildable and never replaces originals.
Segment = Learning Thread`thread_id` means the session-local contiguous Segment. A meaningful transition starts a new Segment; an old noncontiguous Segment is never reopened.
Durable Conversation TopicOptional Grade-scoped navigation identity. EPHEMERAL is default; reuse before create; ambiguity must not silently create durable memory.

Return to an earlier topic inside the same Session → create a new Segment and optionally reuse the same conversation_topic_ref.

Bounded Tutor-facing Context

1 · Current TurnCurrent Lina input is authoritative.
2 · Immediate BridgeEnough directly preceding exchange to resolve opaque follow-ups such as “ليش؟” or a short answer.
3 · Current SegmentBounded relevant context from the active Learning Thread / Segment.
4 · Same-topic ResumeLatest prior Segment of the same Durable Conversation Topic only when resuming within the current Session.
5 · Intelligence / RAGRelevant Learner Intelligence/Open Loops and question-driven grounding enter separately.
6 · Safety DecisionEffective policy directive remains independent and upstream authority.

Not loaded automatically: full Session history · all Topic history · prior-session transcripts · archive vector memory. Historical lookup is a deferred on-demand seam.
