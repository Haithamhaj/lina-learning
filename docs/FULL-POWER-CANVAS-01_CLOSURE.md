## Result and boundaries

The retained architecture is one Tutor, one bounded Canvas Agent, PostgreSQL Studio state, and immutable ObjectStorage Builds. CREATE receives strict scalar/semantic fields; the application owns envelopes, identity, provenance and the canonical Manifest. Generated JavaScript passes parse-only Node validation and the isolated production sandbox. CREATE now returns real wide/narrow browser screenshots, and a small pointer probe when a draggable exists, to the same Canvas Agent before finalization. One source-only visual correction preserves the Manifest, parameters and registry lineage. A technical authoring failure can consume one additional bounded attempt: at most two initial CREATE attempts, one successful preview correction, three total attempts. A failed correction cannot finalize the earlier defective candidate.

This is disposable-owner, real-provider and actual production-renderer/API evidence. It is not authenticated Clerk/Daily login, production deployment, real-Lina learning benefit, or a statistically established success rate. Screenshots are actual persisted/generated output; manual source corrections are explicitly identified below. Automatic preview is a quality check, not a mathematical theorem prover or permission to weaken Tutor authority.

## Root causes and repairs

- Old live backend acceptance did not establish executable browser correctness: the previously accepted Build contained malformed JavaScript, and the old browser fixture substituted another package. The fixture substitution was removed. The new harness fetches the actual Snapshot and owned Build endpoint and uses real operations and Primary Tutor streaming routes.
- Reference-only Scene serialization included `package: null`; the frontend rejected that exact persisted shape. It now accepts null but never inline executable source.
- Permissive CREATE arguments repeatedly failed JSON encoding. The advertised schema now uses strict named scalar parameters and typed semantic lists. Canonical Manifest construction remains application-owned.
- Case-insensitive forbidden-API checking rejected ordinary JavaScript `function`; error wrapping hid real source failures behind misleading Manifest diagnostics. Syntax, security and preview errors now retain bounded actionable reasons.
- Literal-only event matching rejected valid shared pointer handlers. Static known-invalid pairs remain rejected; both the actual host and Studio validate every emitted pair against the canonical Manifest. SELECT/FOCUS carry identity only; values belong to declared mutation actions.
- The original custom path had no real screenshot feedback before finalization. A shared production sandbox document, a bounded Playwright preview process and one same-agent source-only refinement close that gap. The preview has no application session, no network, an opaque-origin iframe, a 25-second process timeout, bounded screenshots and no extra model call. Node, existing Playwright and an installed Chrome channel are required on the composing worker; unavailable preview fails closed.
- Host decorative scaling distorted actual pointer hit testing. Custom visuals are excluded from that transform. The sandbox receives saved semantic values; renderer revision identity and replay are preserved. The agent gets explicit SVG screen-transform, signed-rational and distinct-choice requirements, reinforced by actual pointer feedback.
- Promotion referenced an unbound local variable; structural ADAPT omitted a privacy validator import. Both are fixed. Reuse lookup is owner-filtered; same-owner cross-runtime resolution requires a validated Version and a persisted Scene/Instance binding. Endpoint resolution also checks the exact Scene→Build→Manifest chain and all digests.
- ADAPT now creates an immutable child Build and Version with explicit parent IDs. Reviewed source corrections of registered Builds create further immutable child Versions and Instances, preserving original source, provider proposal, Scene, and events. Ordinary parameter changes remain REUSE.
- Five regression fixtures lagged new tables, migration head and Tutor fields. A sixth pattern test depended on wall-clock decay of an old fixture date; only its test clock was fixed. Learning Intelligence rules were not changed.
