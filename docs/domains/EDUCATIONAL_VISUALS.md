# Educational visuals policy

Use a visual representation when language alone is becoming repetitive, hesitant, or too long for the learning need. A visual must serve orientation, explanation, feedback, interaction, or a checkable learning objective—not decoration.

TeachingMode is the turn’s broad interaction posture; TeachingStrategy is the support/intervention flow; TeachingMethod is the pedagogical representation. Canvas is one representation surface, not a method or a separate authority. The Tutor selects the semantic direction in the primary call; runtime validates available capabilities and preserves safe fallback to chat.

Use project-owned typed specifications and reusable renderers. Native React/SVG, Motion, JSXGraph, React Konva, and MathLive are the current renderer direction. Generated HTML/SVG is sandboxed fallback-only. Runtime guidance under `runtime/` remains operational guidance and is not replaced by this policy.
